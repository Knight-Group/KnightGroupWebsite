## Page Roles

- `/Services/handyman` is the core service page for broad handyman terms.
- `/services` is the service hub and should route visitors into the correct service page.
- `/pricing` owns pricing-intent queries and should link to service pages with clear job-type cards.
- City pages own city-qualified handyman terms and should link to service-specific proof.
- Gallery detail pages are proof assets, not primary money pages. They should support service and city pages with before/after evidence.

## Internal Linking Rules

- Link to the primary page for a query with descriptive anchor text, not generic “learn more.”
- Do not create a new page for a query if the map already assigns ownership and the current page can be improved.
- When a service page mentions a city with GSC demand, link to the matching city page.
- When a city page mentions a service with proof, link to the matching service page and a relevant gallery detail page.
- Pricing pages should link to the service pages where price-sensitive users are most likely to convert.
