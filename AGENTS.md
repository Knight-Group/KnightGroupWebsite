# GSC audits for this site

Google Search Console audit data is **not stored in this folder by default** — it is generated by `E:/GSC Auditer` and copied here after each run.

## Latest audit

Check `.gsc-audit-latest.json` in this folder for the path to the most recent export.

## Request a full audit (API + Playwright UI)

From this workspace, ask in chat:

> Do a full GSC audit with Playwright exports

Or run:

```powershell
node E:\GSC Auditer\tools\audit.mjs --ui
```

Outputs land in `gsc-audit/<date>/` (report, analysis, API JSON, UI ZIPs).
